# Rot City — กระดานภารกิจ CEF

เปิด `index.html` ใน Chrome หรือ Edge เพื่อดูตัวอย่าง อัปเดตชื่อ คำอธิบาย สถานะ รางวัล และความคืบหน้าได้ผ่าน JavaScript ตัวอย่างมีรายการตามต้นฉบับ 8 ช่อง ปุ่มยกเลิกและ Escape ปิดหน้าต่างกระดาน

| ไฟล์ / โฟลเดอร์ | ใช้งาน |
| --- | --- |
| assets/glyphs/ | PNG โปร่งใส 13 ชิ้น มีไอคอนภารกิจ รางวัล และปุ่ม |
| assets/icons/ | ไอคอน 16 ชิ้นที่เก็บพื้นกรอบจากต้นฉบับ มีตรา Rot City และไอคอนน้ำขนาดใหญ่ |
| assets/ui/ | เฟรมหลัก พื้นแถวปกติและแถวที่เลือก พื้นปุ่มรับและยกเลิก 5 ชิ้น |
| assets/raw/ | 18 ชิ้นครอปตามต้นฉบับ มีทั้งข้อความและภาพประกอบ ใช้เทียบตำแหน่งหรือทำหน้าคงที่ |
| asset-map.json | พิกัด x/y และขนาดพิกเซลของแต่ละชิ้นจากต้นฉบับ 1168 × 784 |
| asset-preview.png | ภาพรวมชิ้นส่วน |

ต้นฉบับเป็น JPG ชั้นเดียว พื้นที่ใต้ตัวหนังสือบางส่วนถูกสร้างทดแทนและขอบของไอคอนโปร่งใสคำนวณจากความต่างสีกับพื้นหลัง จึงอาจเห็นรายละเอียดขอบต่างจากภาพต้นฉบับ

## เชื่อมกับ SA-MP CEF

วางทั้งโฟลเดอร์ไว้ในตำแหน่งที่ตัว CEF ของโปรเจกต์เปิด URL ได้ โดยคงโครงสร้างไฟล์เดิม ให้ฝั่ง Pawn โหลด `index.html` แล้วส่งข้อมูลผ่านอีเวนต์ CEF ตามตาราง

| ทิศทาง | อีเวนต์ | พารามิเตอร์ |
| --- | --- | --- |
| Pawn → CEF | `rotcity:missions:data` | JSON string ที่เป็น array ของภารกิจ |
| Pawn → CEF | `rotcity:missions:show` | เปิดกระดาน |
| Pawn → CEF | `rotcity:missions:hide` | ซ่อนกระดาน |
| CEF → Pawn | `rotcity:missions:accept` | ID ภารกิจในรูป string |
| CEF → Pawn | `rotcity:missions:close` | ไม่มีพารามิเตอร์ ให้ Pawn คืนการควบคุมผู้เล่นและปล่อยโฟกัส CEF |

ตัวอย่าง JSON สำหรับส่งด้วยอีเวนต์ `rotcity:missions:data`

```json
[
  {
    "id": "water_01",
    "icon": "water",
    "title": "ส่งน้ำเข้าค่าย",
    "description": "นำน้ำสะอาดไปส่งยังค่ายผู้รอดชีวิตทางตะวันตกของเมือง",
    "state": "idle",
    "current": 0,
    "total": 3,
    "rewards": [{"icon": "reward_water", "text": "น้ำดื่ม ×3"}]
  }
]
```

ค่า `state` ใช้ `idle`, `active` หรือ `complete` ค่า `icon` ของภารกิจใช้ `water`, `walker`, `runner`, `brute`, `horde`, `scrap`, `toxic`, `mutant` ไอคอนรางวัลใช้ `reward_water`, `reward_parts` หรือ `reward_reputation` เมื่อ Pawn รับภารกิจสำเร็จ ให้ส่งข้อมูลล่าสุดกลับมาด้วยอีเวนต์ data เพื่ออัปเดต UI

ทดสอบหน้าเว็บด้วย Console ได้ผ่าน `RotCityMissions.setMissions([...])` และ `RotCityMissions.show()` ตัวอย่างในเบราว์เซอร์เปลี่ยนสถานะในหน้าได้ทันที ส่วนในเกมสถานะขึ้นตามข้อมูลที่ Pawn ส่งมา
