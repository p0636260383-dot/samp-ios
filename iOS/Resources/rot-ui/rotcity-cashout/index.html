ระบบถอนเงินจริง (CASHOUT REWARDS)

แลกเปลี่ยนไบโอคอร์ (Bio-Core) เป็นเงินบาทเข้าบัญชีธนาคารหรือพร้อมเพย์

ยอดไบโอคอร์ของคุณ 0 CP
อัตราแลกเปลี่ยน 1 CP = 1.00 บาท
ถอนขั้นต่ำ / ค่าธรรมเนียม 100 CP / 15%
เงินจริงที่จะได้รับ: 0 บาท

⚠️ แอดมินจะตรวจสอบประวัติการได้มาของพอยท์และดำเนินการโอนเงินภายใน 24 ชั่วโมง
