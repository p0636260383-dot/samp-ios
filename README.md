# ROT CITY iOS Native Client (skeleton)

This directory is a new iOS port scaffold. It does not contain a runnable game yet.

## Layout
- `src/ios`: Swift/Objective-C UI and app lifecycle
- `src/core`: platform-independent C++ core (network/RPC/protocol)
- `src/platform`: platform abstraction interfaces
- `.github/workflows`: macOS build pipeline
- `docs`: audit and dependency notes
